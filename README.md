# Чистая установка 
**Если вы устанавливаете Renegades Add-Ons с нуля:**
1. Подготовьте чистую директорию игры. Получите свежую копию ванильной X3AP.
   - Скопируйте её в новое место.
   - Переименуйте папку во что-то вроде: **Mayhem_3_Renegades**
     - Далее она будет называться "директория Renegades".
   - НЕ ПЕРЕМЕЩАЙТЕ вашу копию в папки **"/Program Files" или "/Program Files (x86)"**.
   - Выполните шаг **"a" или "b"**, в зависимости от того, где вы приобрели копию **X3AP**.
  
   a. Если вы приобрели **X3AP в Steam:**
     - Ваша игра должна быть зарегистрирована на форумах Egosoft, чтобы скачать исполняемый файл **"no-Steam"**.
     - Скачайте **"no-Steam" X3AP.exe здесь:** https://www.egosoft.com/download/x3ap/bonus_en.php
     - Замените **X3AP.exe** внутри вашей директории Renegades версией **"no-Steam"**.
     - Убедитесь, что:
       - Язык игры установлен на **английский (проверьте свойства X3AP в Steam)**.
       - Бонусный пакет **отключен (несовместим с Mayhem 3)**.
     - См. эту статью FAQ (https://www.egosoft.com/support/faq/faq_answer_en.php?answer=2110&version=0) касательно регистрации ваших игр из Steam.
  
   b. Если вы приобрели X3AP в GOG:
     - Ваш текущий X3AP.exe совместим. Никаких изменений не требуется.

2. Установка базы Renegades
   - Скачайте **"Renegades Full Install"** из основной темы Renegades ИЛИ с Google Drive. (Они идентичны. По состоянию на июль 2025 года базовая версия Renegades — 5.4.)
   - Извлеките всё содержимое в вашу директорию Renegades.

3. Установка аддонов (Add-Ons)
   - Скачайте zip-архив Add-Ons в разделе "Releases".
   - Откройте архив и перейдите в папку внутри. Убедитесь, что вы видите:
     - addon
     - mayhem_data
     - cleanup.bat (обновленный)
     - Другие сопутствующие файлы
   - Извлеките всё содержимое в директорию Renegades.
   - Запустите *cleanup.bat*
  
4. Инициализация системы галактики **(Обязательный порядок)**
   - **Шаг А:** Используйте *оригинальный Galaxy Generator (только для инициализации)*
     - Примечание: этот шаг инициализирует зависимости, необходимые для ZMap. Оригинальный Galaxy Generator вам больше не понадобится после завершения шага А. НЕ ИСПОЛЬЗУЙТЕ галактику, созданную на этом шаге, для игры.
     - Откройте "Mayhem Galaxy Generator.exe" (находится в корне Renegades).
     - Нажмите кнопки "Default" для автоматической установки:
       - Root path (корневой путь)
       - Savegame path (путь к сохранениям)
     - Проверьте правильность путей.
     - Сгенерируйте галактику.
     - Подтвердите, что галактика появилась в "mayhem_galaxies". 
  
   - **Шаг Б:** *Используйте ZMap (реальная галактика)*
     - Из корневой папки Renegades перейдите в папку ZMap.
     - Откройте "X3_Mayhem_Galaxy_Generator.exe".
     - Установите:
       - Game folder path (корневая директория Renegades)
       - Savegame path
     - Сгенерируйте вашу галактику.
     - Сохраните её и сделайте активной (set as active).

5. Дополнительная настройка
   - Вы можете настроить параметры галактики перед генерацией.
   - В ZMap вы можете использовать **"Weapons and Ships Editor"** (третья иконка сверху слева), чтобы рандомизировать характеристики кораблей и оружия.
   - Вы можете редактировать конфигурационные файлы:
     - /t/9972-L044.xml
     - /t/9973-L044.xml
    
6. Финальный шаг
   - Запустите X3AP.exe из директории Renegades.
   - В главном меню убедитесь, что имя активной галактики отображается в правом нижнем углу. Если оно появилось — установка завершена.
    
# Установка поверх существующей Renegades 5.4 или обновление аддонов
Если вы устанавливаете поверх Renegades 5.4 или обновляете текущие аддоны:
  - Скачайте последний пакет Add-Ons и извлеките его содержимое в корневую директорию игры, разрешая замену файлов при запросе.
  - Если ZMap установлен вне корневой директории игры, вручную скопируйте **"TShips.txt" и "TBullets.txt"** из релиза в вашу папку ZMap.
    - Это относится только к очень старым установкам, где ZMap стоял отдельно от Renegades.
    - Если ZMap находится внутри папки Renegades (стандартная установка), дополнительных действий не требуется.

# Политика версий
- Минорные версии (например, 1.X) могут изменять поведение постоянного мира и в определенных случаях могут потребовать начала новой игры.
- Версии патчей (например, 1.5.X) безопасны для обновления посреди игрового процесса.
